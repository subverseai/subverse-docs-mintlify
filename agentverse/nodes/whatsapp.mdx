# WhatsApp Business Cloud

The **WhatsApp Business Cloud** node lets you send messages and share media via the WhatsApp Business API from within an orchestration.

![WhatsApp Business Cloud Node](/images/agentverse/whatsapp-action-node.png)

---

## Credentials

This node requires a **WhatsApp** credential.

To create a credential:
1. Go to **Settings → Credentials → New Credential**
2. Select **WhatsApp**
3. Enter your WhatsApp Business API **Access Token** and **Business Account ID**

---

## Operations

### Message

| Operation | Description |
|---|---|
| `Send Text` | Send a plain text message to a phone number |
| `Send Template` | Send an approved WhatsApp message template |
| `Send Media` | Send an image, video, audio, or document |

---

## Parameters: Send Text

| Parameter | Type | Required | Description |
|---|---|---|---|
| **Credential** | Credential | Yes | Select or create a WhatsApp credential |
| **Sender Phone Number ID** | String | Yes | The phone number ID of your WhatsApp Business sender (found in your Meta Business account) |
| **To** | String | Yes | Recipient phone number in E.164 format (e.g. `+919876543210`) |
| **Message** | String | Yes | The text message to send |
| **Preview URL** | Boolean | No | Enable URL link previews in the message |

## Parameters: Send Template

| Parameter | Type | Required | Description |
|---|---|---|---|
| **Credential** | Credential | Yes | Select or create a WhatsApp credential |
| **Sender Phone Number ID** | String | Yes | The phone number ID of your WhatsApp Business sender |
| **Recipient's Phone Number** | String | Yes | The recipient's phone number in E.164 format |
| **Template Name** | String | Yes | The exact name of the approved message template |
| **Language Code** | String | Yes | Template language code (e.g. `en_US`) |
| **Components** | Collection | No | Template variable substitutions for header, body, and button sections |

## Parameters: Send Media

| Parameter | Type | Required | Description |
|---|---|---|---|
| **Credential** | Credential | Yes | Select or create a WhatsApp credential |
| **Sender Phone Number ID** | String | Yes | The phone number ID of your WhatsApp Business sender |
| **To** | String | Yes | Recipient phone number in E.164 format |
| **Media Type** | Select | Yes | `image`, `video`, `audio`, `document`, or `sticker` |
| **Media URL** | String | One of | Public URL of the media file |
| **Media ID** | String | One of | WhatsApp media ID of a previously uploaded file. Provide either **Media URL** or **Media ID** |
| **Caption** | String | No | Caption text to include with the media (supported for image, video, document) |
| **Filename** | String | No | Display filename shown to the recipient (documents only) |

## Output Data

A successful send operation returns:

```json
{
  "messaging_product": "whatsapp",
  "contacts": [
    {
      "input": "+919876543210",
      "wa_id": "919876543210"
    }
  ],
  "messages": [
    {
      "id": "wamid.XXXXXXXXXXXX"
    }
  ]
}
```

Reference in downstream nodes:

```
{{ whatsapp.messages[0].id }}
{{ whatsapp.contacts[0].wa_id }}
```
