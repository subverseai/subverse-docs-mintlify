<Update label="November 18, 2026" tags={["Custom Functions"]}>
  **TL;DR:** Custom functions can now call partner APIs that only accept requests from whitelisted IP addresses.

  ## What's new

  ### Static IP for HTTP requests

  **What it does:** The [HTTP Send Request](/integrations/agentic-functions/custom-function-actions#http-send-request) action has a new `useStaticIP` option. When you turn it on, the request is sent from SubVerse's fixed IP address, **`15.207.21.5`**.

  **Why it matters:** Many banks, CRMs, and internal enterprise APIs block traffic from unknown IPs. Ask your API provider to whitelist `15.207.21.5` once, and your agents can call those APIs directly.

  ```javascript
  const response = await subverseActions.http.sendRequest({
    options: {
      method: 'GET',
      url: 'https://partner-api.example.com/orders',
      options: {
        useStaticIP: true
      }
    }
  });
  ```

  The option is off by default, so existing functions behave as before. The Code Assistant knows about this option. Tell it the API needs a whitelisted IP and it will add the option for you.
</Update>
