<Update label="Nov 18, 2026">
  ### Static IP for HTTP requests

  Requests can now be sent from SubVerse's fixed IP, **`15.207.21.5`**. Ask your API provider to whitelist it once, and you can reach banks, CRMs, and enterprise APIs that block unknown IPs.

  - **Custom functions:** set `useStaticIP: true` in the [HTTP Send Request](/integrations/agentic-functions/custom-function-actions#http-send-request) action's `options.options`. The Code Assistant can add it for you.
  - **Orchestrations:** turn on **Use Static IP** under **Options** in the [HTTP Request](/orchestration/nodes/http-request) node.

  It's off by default, so existing functions and orchestrations work as before.
</Update>
