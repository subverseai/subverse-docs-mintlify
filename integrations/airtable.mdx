---
title: 'Airtable'
description: 'Connect your Airtable bases so agents and workflows can read, create, and update records.'
---

**Connection type:** Credential

Connect your Airtable bases to SubVerse. Agents can look up records to answer questions, and your Functions and Orchestrations can create and update them. An Airtable event can also start an orchestration.

## What you can do

| Capability | What it does |
|---|---|
| **Read records** | Let an agent look up records to answer questions, such as a booking, a ticket, or a stock level. |
| **Create and update records** | Write to your bases from Functions and Orchestrations, for example logging a conversation or updating a status. |
| **React to changes** | Start an orchestration when something changes in a base, such as a new record. |

## Credential types

| Credential type | Best for |
|---|---|
| **Airtable OAuth2 API** | Most connections. You approve access in Airtable, and SubVerse keeps the connection refreshed. |
| **Airtable Personal Access Token API** | A quick setup tied to one person's Airtable account |
| **Airtable API** | Not available. Airtable retired API keys. |

## What you'll need

- An Airtable account with access to the bases you want to use
- Permission to create an OAuth integration or a personal access token in Airtable

<Note>
  Step-by-step setup is in the SubVerse dashboard: go to **Integrations → AirTable** and open the **Documentation** tab.
</Note>
