**Connection type:** Channel

Connect your WhatsApp Business number on Dovesoft to a SubVerse chat agent. When customers message your number, Dovesoft forwards the message to SubVerse, and the agent replies on WhatsApp.

## What you can do

| Capability | What it does |
|---|---|
| **Answer customers on WhatsApp** | A chat agent reads incoming messages and replies automatically. |
| **Handle any message type** | The agent can read and send text, images, audio, video, documents, and other WhatsApp message types. |
| **Keep the conversation going** | The agent remembers context for each customer, for 24 hours by default. |
| **Show that the agent is replying** | Customers see a typing indicator while the agent works on a reply. |
| **Send messages from workflows** | Use the channel to send WhatsApp messages from Functions and Orchestrations. |

## How it works

**Customer messages you** → **Dovesoft** → **SubVerse** → **Chat agent** → **Reply via Dovesoft**

After you add the channel, you point your Dovesoft webhook to SubVerse so incoming messages reach the agent.

## What you'll need

- A Dovesoft account with your WhatsApp Business number onboarded and live
- Your Dovesoft API key
- Access to webhook settings in the Dovesoft dashboard
- A chat agent in SubVerse

<Info>
  **Connected directly to Meta instead?** If your number uses the Meta WhatsApp Cloud API directly, use the [WhatsApp Channel](/integrations/whatsapp-channel) integration.
</Info>

<Note>
  Step-by-step setup is in the SubVerse dashboard: go to **Integrations → DoveSoft** and open the **Documentation** tab.
</Note>
