Integrations connect SubVerse to the platforms you already use: phone systems, inboxes, chat apps, AI model providers, stores, CRMs, storage, and any REST API. You manage them all from **Integrations** in the SubVerse dashboard.

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/integrations/integrations.png"
  alt="Integrations page in the SubVerse dashboard"
/>

## Connection types

Each integration card shows how it connects to SubVerse:

| Type | What it does | Examples |
|---|---|---|
| **Channel** | Connects a phone number, inbox, or chat endpoint to an agent, so the agent can talk to customers on it. | SIP, Web Chat, WhatsApp Channel |
| **Credential** | Stores access to another system, used by Functions, Orchestrations, and agents. For AI providers, it lets SubVerse use your own account and API key. | Slack, OpenAI, Shopify, REST APIs |

Some integrations, such as [Email](/integrations/email), support both.

## Connect an integration

1. Go to **Integrations** in the SubVerse dashboard.
2. Find the integration by browsing the groups or searching by name, group, or description.
3. Select **Connect** to add a new connection, or **Manage** to view or change existing ones.
4. Open the integration's **Documentation** tab for step-by-step setup.

<Tip>
  Don't see the platform you need? Select **Request New Integration** on the Integrations page, or connect it yourself with [REST APIs](/integrations/rest-apis).
</Tip>
