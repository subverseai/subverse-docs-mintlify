---

**Connection type:** Channel

Connect your WhatsApp Business number to a SubVerse chat agent. When customers message your number, the agent reads the message and replies on WhatsApp, keeping the context of the conversation.

## What you can do

| Capability | What it does |
|---|---|
| **Answer customers on WhatsApp** | A chat agent reads incoming messages and replies automatically. |
| **Handle any message type** | The agent can read and send text, images, audio, video, documents, and other WhatsApp message types. |
| **Keep the conversation going** | The agent remembers context for each customer, for 24 hours by default. |
| **Show that the agent is replying** | Customers see a typing indicator while the agent works on a reply. |
| **Send messages from workflows** | Use the channel to send WhatsApp messages from Functions and Orchestrations. |

## How it works

**Customer messages you** → **WhatsApp (Meta)** → **SubVerse** → **Chat agent** → **Reply on WhatsApp**

When you save the channel, SubVerse sets up the Meta webhook for you. No manual webhook setup is needed.

## What you'll need

- A Meta Business account with a WhatsApp Business Account
- A phone number added and verified on the WhatsApp Business Platform
- A permanent access token from a Meta system user
- Your WhatsApp Business Account ID and phone number ID
- A chat agent in SubVerse

<Info>
  **Only need WhatsApp APIs in your workflows?** To call WhatsApp APIs or react to WhatsApp events in Functions and Orchestrations without an agent, use the [WhatsApp](/integrations/whatsapp) integration.
</Info>

<Note>
  Step-by-step setup is in the SubVerse dashboard: go to **Integrations → Whatsapp Channel** and open the **Documentation** tab.
</Note>
