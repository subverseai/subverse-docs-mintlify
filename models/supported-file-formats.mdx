---
title: 'Supported File Formats'
description: 'File formats you can use with SubVerse'
---

SubVerse supports the following file formats.

## Images

| Format | File extension | MIME type |
|---|---|---|
| JPEG | `.jpeg` | `image/jpeg` |
| JPG | `.jpg` | `image/jpeg` |
| PNG | `.png` | `image/png` |

## Documents

| Format | File extension | MIME type |
|---|---|---|
| PDF | `.pdf` | `application/pdf` |
| Word document | `.docx` | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |

## Spreadsheets and data

| Format | File extension | MIME type |
|---|---|---|
| CSV | `.csv` | `text/csv` |
| Excel workbook | `.xlsx` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |

<Note>
  JPEG and JPG are the same image format with different file extensions. Both are supported.
</Note>
